# SafeCart deployment agent rules

- This repository is the competition submission entry point and integration contract.
- Keep service source in pinned Git submodules; never duplicate implementation here.
- Do not add a runtime service without a documented ownership and release boundary.
- Never reference a floating branch in the evaluator path.
- Do not add scraping to runtime composition.
- Do not commit secrets, raw data, private screenshots, model weights, or generated files.
- Treat a submodule update as a release change and validate its service CI first.
- Use English for code, comments, identifiers, and commit messages.
- Never commit, push, pull, merge, rebase, or create branches unless the user explicitly
  requests that Git action.
